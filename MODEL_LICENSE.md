The historical release tag `0.1.1rc0` points to `e1052df`. FINISH-001 measured SHA-256 `cd28f55fbbc1829f99d9ac9b38a16d259a22889739c8728ea877610201feff7b`. The checkpoint is absent from Git and APKs.
